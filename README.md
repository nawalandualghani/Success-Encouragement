# 🎯 Daily Habit Tracker & Routine Manager

تطبيق سطح مكتب تفاعلي مبني باستخدام **Python** و **CustomTkinter** مع قاعدة بيانات محليّة **SQLite**، مخصص لتتبع العادات اليومية، الروتين الروحاني والصحي، وحساب نسبة الإنجاز اليومي بشكل مرن ومباشر.

## ✨ المميزات الرئيسية
- **قائمة عادات جاهزة ومخصصة:** يتضمن الروتين اليومي (قيام الليل، الأذكار، الصلوات، ورد القرآن، الرياضة، تعلم اللغات، المشاريع).
- **إمكانية إضافة عادات جديدة:** تصنيف العادات حسب الفئات (طاعات، صحة، تطوير ذات، إنتاجية).
- **حفظ تلقائي واستمرارية:** يعتمد على قاعدة بيانات SQLite لحفظ حالة الإنجاز لكل يوم على حدة.
- **شريط تقدم تفاعلي:** يوضح نسبة الإنجاز المئوية لحمسك على إكمال اليوم.
- **واجهة عصرية (Dark Mode):** تصميم هادئ ومريح للعين يدعم الواجهات الحديثة.

## 🛠️ التقنيات المستخدمة
- **Python 3.10+**
- **CustomTkinter** (للواجهة الرسومية الحديثة)
- **SQLite3** (لإدارة وتخزين البيانات محلياً)
